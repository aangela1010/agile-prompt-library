# Examples

Each file in this folder shows a complete, ready-to-use run of the corresponding
prompt. Examples reflect the refined prompt, not the steps taken to get there.

## What each example contains

- **Raw Notes** the source material as it existed before being formatted into
  the prompt
- **Prompt** the filled-in prompt exactly as it should be sent to Claude
- **Output** the best output produced by the prompt
- **Notes** anything worth knowing before you use it: what to specify upfront,
  what the prompt does well, any edge cases worth watching

## How to use these

Copy the prompt section, replace the content with your own data, and paste it
into Claude. The raw notes and output sections show you what good input and
output look like so you can calibrate your own.
